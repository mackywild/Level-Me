# 回復アイテム基盤

## 今回の範囲
HP・物理エネルギー・魔法エネルギーを対象に、最大値に対する割合回復を定義する。使用は戦闘外のみ。個数1を消費し、回復量は最大値を基準とした整数切り捨て（最低1）、不足量を上限とする。満タンなら消費しない。割合・丸め・満タン時の扱いは正式承認前の実装案である。

Controllerでは作業用Stateに自然回復を先に反映してから使用条件を検証する。失敗時は作業用Stateを破棄し、成功時のみ消費・回復・使用番号を一括保存して公開する。共有inventoryBusyを使用し、同一セーブ世代内で使用番号の再送を拒否する。画面確認に備え復元世代を必須引数とした。旧セーブに使用番号がない場合は0、不正型・負数は拒否する。

## 試験用定義と本番制約
HP20%、物理15%、魔法50%は試験値であり、本番カタログは空。既存素材マスターと正式な回復品の統合は行っていない。本番マスター設定経路では非空の回復カタログを拒否する。直接依存注入は試験用。既存の召喚・強化・分解・ショップの無効状態を維持する。

## 後続

## 回復品候補マスターと使用画面
回復候補9種（HP20/50/100%、物理15/30/50%、魔法15/30/50%）を追加。名称・ID・N/R/SRの割り当て・割合は未承認候補。素材区分と別配列で管理し、素材とのID重複、候補内重複、区分、希少度、回復量を検証する。recoveryEnabled=falseを維持し、trueは明示的に拒否する。既存召喚候補・販売商品への追加は行わない。
回復量計算は最大値を100で割った商と余りに分け、整数乗算overflowを回避する。所持品画面では既知回復品に対象・割合・予定量・使用可否を表示し、確認時の使用番号と復元世代を確定時に照合する。自然回復で予定量が変化し得ることを明示。満タン等で拒否した場合は作業用自然回復も未公開となり、再描画時にプレビューを再取得する。通常の自然回復更新は既存経路に従う。
正式マスターからは回復カタログを空で公開し、非空の直接注入は試験経路のみ。固定時計による自然回復境界・復元競合・旧実ファイル/不正import・使用画面再入場等の追加試験は後続。戦闘中使用、価格、入手先、正式有効化、実機/署名も未完了。
