# スキル習得・装着基盤

能動スキル6枠、パッシブスキル3枠を独立した順序付きリストとして管理する。習得済みスキルのみ装着可能。同一IDの重複習得・重複装着、枠超過、未登録ID、戦闘中の習得・装着・解除を拒否する。解除しても習得記録を保持する。空き枠はリスト末尾として扱い、解除時は詰める。任意位置への装着・入替・並べ替えは未実装。

AppStateData.skillsにversion=1、learned（IDから非負整数への写像）、active、passiveを保存する。旧セーブでskillsが欠落する場合は空。未知version、不正ID・値、未習得装着、重複・枠超過を拒否し、共通保存検証で未承認IDと種別不一致を拒否する。learnedの値は将来の熟練度用に予約し、現段階は習得時0、加算・レベル計算なし。正式熟練度規則・上限・移行は後続で決定する。

Controllerは既存inventoryTransactionと復元世代照合、作業用stateの保存成功後公開を再利用する。習得・装着・解除は通貨を変更しない試験用基盤。習得条件・費用・個別スキルの性能・戦闘効果・熟練度は未承認であり、本番SkillCatalog.productionは空。実マスター設定と非空試験カタログの併用を拒否する。既存基本戦闘コマンドと能力値には変更しない。

枠上限・重複・未習得・解除後の記録維持、旧形式・不正保存・種別不一致、戦闘中拒否、実ファイル遅延保存/模擬失敗/再試行/再起動/外部復元と世代拒否、本番空カタログ・混用拒否のテストを追加。端末内復元/journal、無効な外部バックアップ原本保護、戦闘開始との競合、装着解除後の旧要求再送、装着順と任意枠変更、UI、候補マスター・習得条件・熟練度・戦闘効果は残課題。復元世代照合は同一保存世代内の古い操作要求をすべて排除する仕組みではないため、画面実装時には期待状態または変更番号の照合を検討する。RV-065〜079等の本番安全性ゲートと既存機能無効を維持。ローカルFlutter・実機・正式署名未確認。最新CI全成功とレビュー承認がマージ条件。
