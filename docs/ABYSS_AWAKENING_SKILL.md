# 紅き覚醒の実行基盤

設計書02 v1.1付録Bの紅き覚醒（物攻+30%・3ターン・寿命30日）を非公開試験定義として実装する。本文の覚醒ゲージ案（ゲージ100%、物攻+30%/防御+20%/寿命費-20%）とは区別する。ゲージ、防御補正、寿命割引は今回実装しない。

## 暫定実行仕様
- ST12クリア、無料習得、寿命30日、独立CD5、物理消費0。発動は1コマンド、攻撃せず通常反撃を受ける。次の3成立行動（非攻撃も含む）に物理攻撃補正。発動ターンには残りを減らさない。重複使用不可、不足/未解放/CD/旧turnは非消費。敗北時返還なし。
- 通常紅爪/連爪/複合爪撃および能動物理攻撃に適用。魔法に覚醒補正なし。既存攻撃薬+25%と併存時の物理攻撃は高い方のみ（+30%）、魔法は従来の薬効果のみ。既存加速・会心・乱数・防御・丸め・時間停止耐性と解放条件は維持。覚醒は既存の停止や複合技を解放しない。
- 覚醒専用の残りターンを装着戦闘のみ保存。欠落/不正型/範囲/独立CDとの不一致/非装着の状態を拒否。旧非装着戦闘の形式は維持。勝利/敗北/撤退で破棄。寿命・効果・熟練度・反撃結果を既存の作業状態保存後公開で処理する。
