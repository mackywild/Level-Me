# 全回復薬の暫定仕様

HP・物理エネルギー・魔法エネルギーの不足分を同時に回復する候補。100%固定、1個消費、全資源満タン時は非消費。戦闘中は固定ステータスを基準に回復後に既存反撃・ターン経過を適用する。戦闘外は既存自然回復後に判定する。既存の使用番号・復元世代・一括保存を維持する。回復量の既存int戻り値は3資源の合計であり、個別資源の回復量とは異なる。合計がint範囲を超える異常値は消費前に拒否する。個別回復量のUI・ログ表示は後続。

候補 item:recovery_all / 全回復薬 / SSR は未承認。回復マスターの無効状態、召喚・販売への未登録を維持する。浄化、消費軽減、敵再生抑制、致死耐性は別PR。RV-059の戦闘乱数確定保存は本番有効化前の必須課題。RV-061のバフ候補数値型厳密化を今回追加。実ファイル保存失敗・再起動、戦闘反撃、満タン・合計overflowの試験を追加。戦闘中保存失敗、復元競合、UI個別表示、既存残課題、実機・正式署名は未検証。正式仕様・価格・供給経路は未承認。
