# 戦闘敵定義snapshot v2

PR78の戦闘実行規則v1に続くRV-071/131の部分対応。新規戦闘のみexecutionVersion=2として、敵遭遇の13項目（ID、stage、title、enemy、最大HP、攻撃、防御、G、main、基本寿命、rank、時間耐性、再生率）を開始時に固定・保存する。既存world.version=1とバックアップ形式は変更しない。

## 保存・実行契約
- v2ではencounterSnapshot必須。全項目の欠落/null/誤型、負値、最大HP0、再生率0〜100外、戦闘IDと遭遇ID不一致を拒否。進行IDの消滅・stage/main変更は明示的な移行方針が必要なため復元時に拒否する。現在masterの能力・報酬・表示・耐性・再生率との一致は要求しない。保存値の真正性を証明するものではない。
- 戦闘の最大HP検証、通常/能動攻撃、敵反撃、時間耐性、敵再生・抑制可否、勝利G/基本寿命/初回券種別、戦闘画面の敵表示は固定定義から取得する。寿命報酬率は前PRの保存数値を使用。初回判定は従来のcleared集合を使用し、既存報酬式・技能性能を変更しない。
- 旧v1および版番号なしの戦闘は従来のmaster参照を維持し、未知の開始時定義を補完してv2へ昇格しない。旧v1にencounterSnapshotを混入させない。v1の必須項目検証は維持。戦闘終了後の新規遭遇はその時点のmasterで開始する。
- 本番master変更なし。skillEnabled=false/公開catalog空維持。旧アプリはv2戦闘中セーブを読めないため、更新前に戦闘を終了してバックアップ取得、旧版への復帰は更新前の互換バックアップを使用し原本保全（RV-132）。

## 検証・残課題
新規5試験：master変更後の固定敵HP/名称/反撃/報酬/再戦、停止耐性/再生/抑制判定、全項目の欠落/null/誤型/範囲/ID/版不整合、v1/版なしの互換、実ファイルmaster変更後再起動・勝利。既存の版付き・旧形式fixtureをv2に対応する。
敵定義を変更しても開始時の値を使うが、真正性検証や完全な旧版規則保存ではない。戦闘中ID削除/進行変更は未対応、旧v1の開始時数値は復元不能。技能・報酬率の将来版保持/移行、初回券個数の定義固定、敵master改変・範囲内snapshot改変の耐性、保存前失敗/遅延/競合/外部・端末内復元/journal/widget、正式署名・実機は残る。RV-065〜129/131/132を維持。ローカルFlutter未実行。
