# パッシブスキル能力補正基盤

試験用の固定加算型のみ実装する。基本能力値→装備・強化補正→装着済みパッシブ補正の順で物理攻撃・魔法攻撃・防御を計算する。習得のみ、未装着、効果未定の定義は補正なし。最大3枠、装着順非依存、毎回基本値から計算し累積加算しない。HP・エネルギー上限・会心率・寿命・ターン消費は変更しない。負数・100万超の個別補正・能動種別への誤設定を拒否し、加算の整数上限を検証する。固定加算・数値範囲は暫定案。

Controllerは作業用stateから変更後能力値を検証し、保存成功後に公開する。共通保存validatorでも計算可能性を検証する。戦闘開始時には補正済みWorldStatsを既存battle.statsに固定し、戦闘中の装着変更は禁止。旧戦闘のstatsは再計算せず継続する。戦闘中の現実経験値変動等を理由に保存済みstatsと現行再計算結果の一致は要求しない。パッシブ定義の履歴・戦闘開始時の内訳・改変検出は未実装であり、RV-071/086のマスター移行方針と併せて検討する。

管理画面は公開定義の補正値と現在能力値を表示する。本番skillEnabled=false、空catalogを維持し、既存戦闘性能を変更しない。捕食系6候補の個別性能、割合補正・寿命獲得・特殊効果、熟練度・習得費用は未承認。

装着順・解除・習得のみ・重複加算防止・装備強化併用・不正定義・整数上限・実ファイル保存失敗/再起動/戦闘中変更拒否/外部復元を試験する。遅延保存・競合両順・端末内復元/journal・画面widget・戦闘中の経験値変動/マスター変更・実際の攻撃/防御ダメージの比較は追加検証が必要。RV-065〜088等本番安全性ゲート維持。ローカルFlutter実行・実機・正式署名未確認。最新CI全成功とレビュー承認がマージ条件。
