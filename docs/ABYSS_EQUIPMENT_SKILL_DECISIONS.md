# ABYSS SYSTEM — 装備スキル厳選の決定記録

決定日: 2026-11-26
根拠: LEVEL ME開発者との仕様相談・承認。対象は今回承認された範囲のみ。正式未決の詳細は仮値としても実装しない。

## DEC-001: 獲得経路と完全厳選

- 主人公固有の重要な時間系スキルはストーリー進行による覚醒で解放する。装備のランダム抽選とは独立する。
- 武器・防具系のスキルはガチャ・ショップ交換による装備収集と、装備強化によるランダム付与を中心とする。直接スキル書を交換する別経路の有無は未決。
- 付与されたスキルの種類・Lvは個体固有の結果として保持し、変更・再抽選・強化リセットは不可。理想の組み合わせを求める場合は別個体を入手し、素材を集め直して強化する。
- 既存承認済みの強化上限+20、成功率100%（実行条件を満たす場合）、破壊・消失なしを維持する。
- 周回、素材獲得、装備収集、強化、厳選を育成サイクルとする。

## DEC-002: 希少度別スキル枠とレベル

| 希少度 | 最大枠数 | 付与される強化段階 |
|---|---:|---|
| N | 0 | なし |
| R | 1 | +5 |
| SR | 2 | +5、+10 |
| SSR | 3 | +5、+10、+15 |
| UR | 4 | +5、+10、+15、+20 |
| LR | 5 | +4、+8、+12、+16、+20 |
| GR | 6 | +3、+6、+9、+12、+16、+20 |
| EX | 特殊 | 個別設定（未決） |

R〜GRで抽選Lvは1〜10。低希少度でもLv10の獲得可能性を残し、高希少度ほど高Lvが出やすくする。具体的な確率・EXの扱い・部位別のスキルプールは未決。強化段階に達するたび、その段階の枠に結果を記録する。以前に付いた枠を書き換えない。

## DEC-003: 重複スキルの加算

同じスキルが複数の装備から付与されている場合、適用可能な効果を加算する。例えば同一の物攻上昇効果が各+20%なら合計+40%であり、乗算の+44%や最高値のみの+20%にはしない。この数値は計算例であり正式性能値ではない。

- 加算は効果量の合算を意味する。抽選Lvを合計した新しいLvに置換する仕様ではない。
- 適用する基礎値、固定加算と割合加算の演算順、会心等の上限、異なる効果との重複、能動スキルの重複時の挙動は別途確定する。
- 複数装備での重複加算は確定。同一個体内の重複もDEC-006で承認済み。
- 既存SkillStateの能動6枠・常時3枠と装備個体の付与枠はDEC-005により独立する。

## DEC-004: 装備スキルの有効条件

装備スキルはその装備を装着している場合にのみ有効。解除すると効果/使用権は失われ、再装着するとその個体に付与された同じスキルとLvが有効になる。装備スキルを永久習得する仕組みにはしない。主人公固有の重要な時間権能はストーリー覚醒による永久習得とし装備から独立する。

## DEC-005: 三分類と部位別プール

- 主人公の能動スキル6枠、主人公の常時（共通）スキル3枠、装備個体固有の装備スキルを独立管理する。装備スキルは既存6/3枠を消費しない。
- 武器は攻撃系、防具は防御系、装飾品は特殊効果系の抽選プールを持つ構造を採用する。具体的な効果・ID・Lv曲線・抽選重みは未決。魔遺物と素手の扱い、各EquipmentSlotの具体的な対応、装備由来の任意発動効果のUI/CD/戦闘固定は未決。
- 主人公固有のストーリー覚醒権能を装備抽選に含めない。

## DEC-006: 同一装備内の重複

同一個体の異なる付与段階に同じスキルIDが付くことを許可する。各付与Lvに対応する効果量はDEC-003と同じく加算する。例：GRの6枠すべてに物攻+20%が付けば合計+120%（仮の性能値）。同一IDを理由に付与枠を統合したり、抽選対象から除外したりしない。効果別の上限（例：消費軽減/CD短縮）は別途決定する。

## DEC-007: 強化済み装備の分解と素材還元

強化済み装備も分解可能とし、実際に強化で消費した素材の10%を還元する。30%案は不採用。強化済みという理由だけで拒否する現行実装は後続PRで変更する。

- 還元の基準は消費済み素材。現在のレシピから過去費用を推測して還元する設計は採用しない（技術提案）。素材ID別履歴と還元対象の確定方法、旧強化済み個体の履歴欠落時の扱いを実装前に決定する。
- 端数処理、通常分解報酬との併給、G/他通貨の扱いは未決。10%の素材還元以外は新たな報酬として承認したものではない。
- 既存のお気に入り・装着中・戦闘中・期待強化値の保護条件を維持する方針。実装時は再送・二重分解・素材上限・保存失敗の原本保護も検証する。

## 次に確定する仕様

1. 重要な時間権能の対象ID、ストーリー覚醒地点、その他の時間系・捕食・覚醒系の獲得経路。
2. 各部位の具体的なスキルプール、効果/Lv曲線、加算順・個別上限、希少度別Lv確率、EX、装備由来の任意発動効果。
3. 強化レシピ・素材供給・G費用、ガチャ/ショップ交換品、既存強化済み個体の移行方針。
4. 分解還元の端数・通常報酬・通貨・履歴欠落時の扱い。合成による結果引継ぎや再抽選回避、魔遺物/素手との関係。

## 実装計画（技術提案、一部実装）

- PR #87で希少度別付与段階を純粋なEquipmentSkillPolicyに分離し、全希少度・全強化段階・Lv範囲・不正遷移を試験する。EXは未決として明示的に拒否する。付与の実行や保存とは接続しない。
- 個体IDと付与段階に紐づく変更不能な付与結果（スキルID・抽選Lv等）を版付き保存する。旧形式の読み込みと既存強化済み個体の移行を設計する。
- 既存強化トランザクションと確定抽選を統合する。素材/G・強化値・付与結果は一括確定、保存失敗・再試行・再起動・二重要求で再抽選が発生しない方式を検討する。バックアップ復元による巻き戻しの扱いは別途決定する。
- 装備の付け替え・戦闘開始時の効果固定、加算境界、画面表示、図鑑、周回・素材供給を段階的に実装する。
- RV-150の旧抽選確定取引、RV-151の保存後公開、RV-152の旧データ移行を関連課題として維持する。RV-065〜149の未解消事項も継続管理する。
