# FE問題バンクとIPAシラバスVer.9.2の照合

## 基準

IPAの現行基本情報技術者試験シラバスはVer.9.2です。2026年1月8日掲載の改訂で、下請法に代わり中小受託取引適正化法（取適法）が追加されました。参照先は[IPAのシラバス案内](https://www.ipa.go.jp/shiken/syllabus/gaiyou.html)と[基本情報技術者試験シラバスVer.9.2](https://www.ipa.go.jp/shiken/syllabus/omgdg50000005kpe-att/syllabus_fe_ver9_2.pdf)です。

IPAの試験要綱では科目Aが60問、科目Bが20問で、科目Bはアルゴリズム・プログラミング16問、情報セキュリティ4問です。科目Aのテクノロジ／マネジメント／ストラテジ分野別問題数は公式比率として定められていません。ITパスポートの分野比率を基本情報に流用しません。

## タグ分類の結果

`tool/audit_fe_syllabus.py` は各問題の `subdomain` をIPAの23中分類に対応付けます。これはラベルのカバレッジであり、設問内容のシラバス適合や正答の正しさを証明するものではありません。

- 科目A: 800問。23中分類すべてに5問以上あり、最小件数は5問。
- 科目B: 300問。アルゴリズム194問、情報セキュリティ106問。
- 科目Bの通常問題プールは本試験構成の16:4よりセキュリティ寄りです。これを保ちつつ、演習設定に科目B模擬構成モードを追加しました。このモードは300問のプールから毎回アルゴリズム16問・情報セキュリティ4問を無作為に選び、20問を出題します。
- 科目Aの5問未満という下限は、監査のためのローカル基準でIPAの要件ではありません。

今回、薄かったハードウェア、ユーザーインタフェース、システム企画、技術戦略マネジメント、ビジネスインダストリの問題を補い、各中分類を5問にしました。計算問題や基本用語の反復が多い設問を、DMA・記憶装置、アクセシビリティ、利用者調査、移行計画、技術ロードマップ、製造・小売・物流・金融・農業の情報システムなどの設問に置き換えました。薄い分野を補う20問、ビジネスインダストリの既存問題の改稿、現行法令を扱う2問を合わせ、23問を改稿しています。設問数はA800/B300を維持しています。

取適法の対象取引における取引条件の明示と、給付受領後60日以内のできる限り短い期間に支払期日を定める原則を問う問題を収録しました。参照は[中小企業庁の取適法概要](https://www.chusho.meti.go.jp/keiei/torihiki/2026/260727001/001.pdf)です。

## 品質確認と限界

- 構造検査は4択・正答index・解説・ID・件数などを確認します。
- 自動類似度監査の既定しきい値は3-gram Jaccard 0.72です。これは表層類似の検出に限られ、意味的重複がないことの証明ではありません。
- 改稿した23問は4択、正答、設問ごとの解説を備えます。今回更新した内容について正答と解説の整合を手作業で確認しました。
- `distractorRationales`（誤答肢ごとの個別解説）は任意の拡張です。全1,100問で未設定であり、詳細な設問解説とは別に扱います。
- 既存追加問題978問すべてを独立した外部専門家が確認したわけではありません。全問の意味的重複、シラバス小分類への適合、正答・解説の独立レビューは引き続き必要です。
- `python3 tool/audit_fe_syllabus.py --strict` は未分類ラベルまたは科目A中分類5問未満があれば失敗します。現在は全分類が基準を満たす想定です。

## 残課題

1. 科目B模擬構成モードの出題と記録が既存の履歴・復習・分析機能と統合されることを、Flutterテストと実機で確認する。
2. 全設問をIPAシラバスの小分類ごとに精査し、正答・誤答肢・解説を独立レビューする。
3. 追加22問を含む問題バンク全体の意味的重複を人手で最終確認する。
