# スキル熟練度・レベル成長基盤

試験規則：実行定義のある習得・装着済み能動スキルの成立行動1回につき熟練度1、初期Lv1、10回ごとにレベル+1、最大Lv10（熟練度90）。上限で飽和し、上限到達後も使用可能。勝利・敗北にかかわらず成立行動を対象とする。パッシブ・実行定義なし・通常攻撃・習得・装着・解除は加算対象外。解除後も熟練度を保持する。成長による威力・消費・CD・能力値変化なし。

SkillState version2ではlearnedを熟練度として利用する。整数0〜90、revision必須。version1は従来通り値0のみ許容しrevision欠落0で移行する。旧skills欠落は空。未知version・不正値・未承認ID・実行定義なしの非0熟練度を拒否。旧試験データの任意非0予約値は移行しない。変更番号は装着構成専用のまま、熟練度変更では進めない。

Controllerの戦闘ID/ターン/復元世代の照合、作業用state、保存成功後公開を維持し、戦闘結果・消費・乱数・報酬・熟練度を一括保存する。戦闘不成立・保存失敗・古い要求では加算しない。バックアップ復元は復元時点の値に戻る。管理画面は習得済み実行可能スキルのレベル・熟練度を表示。

境界・上限・旧形式・不正値・未承認成長・CD/不足/旧ターン・勝敗・解除保持の単体試験と既存実ファイル勝利保存失敗/再起動試験の熟練度検証を追加。非致死実ファイルでの成長/CD/乱数の同時保存、遅延保存・競合・外部/端末内復元/journal・widget・旧実ファイル移行は追加検証が必要。正式成長曲線・敗北時加算・反復稼ぎ対策・パッシブ成長・性能反映・旧版アプリへのダウングレード方針は未承認。RV-065〜091等安全性ゲート維持。本番skillEnabled=false/空catalog維持。ローカルFlutter・実機・正式署名未確認。最新CI全成功とレビュー承認がマージ条件。
