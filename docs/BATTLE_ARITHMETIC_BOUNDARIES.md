# 戦闘算術の境界安全化

RV-140/141の部分改善。Dartネイティブの符号付き64bit整数を対象とする。既存の勝利報酬の超過拒否とは別に、既存仕様が上限までの回復であるHP/エネルギー/保留回復の桁あふれを防止する。

- 回復は残容量と回復量・回数を除算で比較し、安全な場合だけ積・加算を実行する。自然回復のHP5%は整数除算HP~/20で算出し最小1を維持する。巨大HPでの浮動小数点丸め差を除き通常の性能は変更しない。上限低下時の現在値の正規化、時刻余り、戦闘中の保留、レベルアップ全回復も維持する。負の努力報酬は拒否する。
- ダメージ式は既存の浮動小数演算順・会心・乱数・最小1を維持。非有限/負の入力と非有限結果を拒否し、整数変換の上限を明示する。極端な防御強化加算は残容量で64bit上限まで飽和する（従来のmax-100制約は除去、分母は従来double）。ダメージの高精度化や丸め規則の全面変更は行わない。
- 攻撃分類のswitchを全enum明示とし、新しい種別追加時の勝利報酬容量検査漏れをコンパイル時に検出できるようにする。現在の攻撃分類・拒否方針は変更しない。
- 保存形式、スキル性能の正式値、本番master、公開設定は変更しない。
