# 静止爪撃・超時連撃の実行基盤

設計書02 v1.1付録B・時間重奏案：静止爪撃は時間停止＋紅爪の停止可能な強撃、寿命45日。超時連撃は停止＋加速、400%、寿命90日。静止爪撃の250%は未承認の試験値。超時連撃は既存複合爪撃の400%/90日と同等の単発として試験実装する。

## 暫定仕様
- 静止爪撃はST12、超時連撃はST06とST12の両クリアを習得・実行で要求。無料習得、装着必須。物理消費0、寿命45/90日、省力薬非軽減。
- 既存時間停止・複合爪撃とstopCooldown=5を共有し、独立CDは0。発動ターン非減算、次の成立5行動で満了。停止耐性は敵反撃の停止だけを無効化し、攻撃と消費は成立する。
- 通常の物理攻撃・会心・乱数・紅き覚醒・薬補正・勝利処理を再利用。既存自己加速の残り回数を消費/増加しない。敵撃破時は即勝利。毒・バフ・履歴等の経過は既存共通経路。
- 装着snapshotの効果/ID/威力/費用/独立CD0を検証。既存stopCooldownを保存するため新規保存項目なし。寿命・勝敗・熟練度・CDは既存の作業状態保存後公開で処理する。
- 本番skillEnabled=false・公開catalog空維持。本番マスター変更なし。未公開ST12は試験専用拡張マスターのみ使用。
