# 戦闘乱数の永続化（RV-059）

戦闘開始時に新規seedを生成し、戦闘中はWorldBattleのrngVersion=1、rngState（1〜2147483646）を使用する。Park–Miller法（乗数48271、法2147483647）で会心、威力変動、回避の順に必要な場合のみ状態を進める。旧戦闘セーブの両項目欠落時は戦闘IDとターンから決定的に移行する。片方欠落、未知version、非整数、範囲外は拒否する。旧版のRandom系列そのものは再現しない。

通常戦闘開始・通常コマンドも回復・バフと同様に作業用Stateで実行し、保存成功後に公開する。同一の確定済み戦闘状態・同じ行動・同じ外部条件から、模擬保存失敗や再起動後も同じ乱数結果を再現する。戦闘開始自体の保存失敗では新規seedが変わり得るが、未確定の戦闘であり行動結果はまだ存在しない。終了時刻や保留回復などの外部条件は別管理。通常コマンドの画面経路は復元世代を渡すが、既存直接APIは任意引数。手動backup巻戻しやセーブ編集による予測・改変、任意I/O障害、旧版ダウングレードは保証外。PRNGは暗号用ではない。固定乱数の既存WorldEngineテスト注入経路は永続化対象外であり、本番Controllerでは使用しない。

既知系列、JSON往復、旧セーブ、不正値、乱数非消費、通常/回復/バフの実ファイル遅延保存・失敗・再起動・同一結果・再送拒否・外部復元世代の試験を追加。端末内復元/journalでの不正乱数原本保護、行動種別間の競合、勝利/敗北での結果一致、停止時の乱数非消費、画面再入場は追加検証が必要。既存RV-060〜064等の残課題と全候補の本番無効を維持する。ローカルFlutter・実機・正式署名未確認。最新CI成功とレビュー承認で本対応を評価する。
