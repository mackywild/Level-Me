# ABYSS SYSTEM 経済基盤

## 今回の範囲
WorldStateに魔晶石残高とショップ取引番号を追加する。既存セーブで項目がない場合は0、存在する場合は非負整数のみ許容する。G、武装券、物資券、寿命、旧ガチャ券とは別資産であり、移行・初期配布は行わない。

ショップの固定商品は素材ID、支払通貨、価格、数量を保持する。今回の対象は素材購入のみ。戦闘中禁止、取引番号照合、残高・素材加算上限、商品参照を検証し、作業用Stateを保存成功後に公開する。分解・保護設定と共有busyを利用する。保存済み取引番号により同一セーブ世代の重複購入を拒否する。

## 経済案（未承認）
Gは戦闘など既存の供給経路から獲得し、素材購入・強化などに消費する。魔晶石は将来の装備分解報酬・素材交換等に利用する案。今回魔晶石の獲得処理は追加しない。既存の素材直接還元案との関係は別途決定する。

試験用商品は鉄2個/10G、合金1個/魔晶石3個。正式価格・報酬・交換レートではない。本番カタログは空のままとする。価格・数量の技術上限100万はバランス上の承認値ではない。

## 残課題
魔晶石の正式獲得・消費方針、分解報酬、ショップ画面、正式商品価格、全装備操作共通busy、素材供給とG収支、券循環、強化補正・正式レシピ、実機・正式署名。既存召喚・強化・分解の無効状態を維持する。手動バックアップで過去世代を復元した場合の巻き戻し防止は対象外。旧アプリへ戻すと新規項目が保存時に失われる可能性があるため、ダウングレード前にバックアップを保持する。

## 深淵商店・魔晶石付与基盤
PR #46の正式承認5項目（独立通貨、旧セーブ初期0、戦闘中購入禁止、一括保存、同一世代の取引番号重複拒否）を維持する。商店画面は商品名・数量・価格・通貨・残高・購入可否を表示し、確認時の取引番号とController内の復元世代を確定時に再照合する。直列キュー内で復元処理を開始する時点で世代を進め、その後の失敗でも古い確認を無効とする。事前validateで拒否された外部importは世代を変更しない。世代は画面内確認向けのメモリ上の値であり、手動バックアップによる永続的巻戻しを防ぐものではない。
分解報酬は素材のみ・魔晶石のみ・併用を設定可能とした。正式報酬は未承認で、試験用魔晶石3個は正式値ではない。付与前に残高加算上限を検証する。従来の装備保護・保存後公開を維持。商品・分解レシピは空のまま。正式価格、供給量、報酬方式、追加競合・復元試験、実機検証は残課題。

## レビュー対応 RV-046〜048
購入と分解の画面確認経路は復元世代を渡す。分解は個体ID・masterId・slot・rarity・強化値も照合する。既存の直接呼び出しAPIでは任意引数を省略できるため、この世代保証は画面確認経路に限定される。外部/端末内復元と復元失敗後の旧世代拒否、事前検証失敗時の世代維持、最新世代の購入を実ファイルで試験する。併用報酬の模擬保存失敗・再起動・外部復元・重複拒否・保護・加算上限を追加検証する。商店の魔晶石支払、保存失敗、再入場、取引番号変化、戦闘中拒否のwidget試験を追加。復元進行中の競合を専用遅延復元で再現する試験と、復元世代変化のwidget試験は残る。正式価格・報酬は未承認のまま。
