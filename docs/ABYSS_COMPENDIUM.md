# 深淵図鑑

既存AbyssInventory.discoveredを発見記録の唯一の保存元として利用する。初回入手時に登録され、消費・分解後も保持される。同一マスターの装備個体は一種類として集計し、所持数は個体数、物資はスタック数を参照する。図鑑は読み取り専用で保存・報酬付与を行わない。バックアップ復元時は復元時点の発見記録に従うため、異なる保存世代をまたいだ発見記録の合算は行わない。

公開済み装備・素材のみを母数にする。現在の候補マスターを試験で有効化した場合は24装備+8素材。回復・バフ・浄化は未承認なので母数にも含めない。本番enabled=falseでは図鑑項目0件、発見率を表示せず公開済み図鑑マスターなしと表示する。未知・非公開IDの発見記録自体は削除しない。未発見枠はdefinition=null、owned=0で、ID/名称/希少度/性能/カテゴリを保持しない。発見済みをID順、未発見を匿名枠として後置する。検索・カテゴリ・希少度絞り込みは発見済みのみ対象とし、未発見枠の情報を検索結果から推測できないようにする。発見率はフィルターに依存しない。クライアント内のアセットやセーブファイル直接閲覧・改変に対する秘密保護ではない。

今回の母数・匿名枠・順序・表示・復元時の扱いは実装上の方針であり、正式マスター公開前に確認する。図鑑達成報酬、入手先、敵図鑑、将来の消耗品公開時の希少度接続は別途設計。実ファイル保存/再起動/外部復元、消費/分解後の保持、読み取り非変更、非公開ID除外、匿名化、検索のwidget試験を追加。実取引経由の遅延保存・失敗、端末内復元、全フィルター・画面遷移widget、全件発見・将来マスター更新の追加試験は残る。既存RV-065〜076等の本番安全性ゲートと各機能の無効状態を維持する。ローカルFlutter・実機・正式署名未確認。最新CI全成功とレビュー承認がマージ条件。
