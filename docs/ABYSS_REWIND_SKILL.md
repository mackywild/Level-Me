# 時間逆行の実行基盤

設計書02 v1.1の時間逆行（ST16、寿命90日、前ターンのHPのみ復元、CD8、消費・報酬は巻き戻さない）を非公開試験定義として実装する。

## 暫定実行ルール
- 「前ターン」は直前に成立した行動の開始時HPと解釈する。戦闘開始時に現在HPを記録し、全成立行動共通の終了処理で開始時HPを前ターン履歴へ移す。回復アイテムの回復前HPも記録できる。勝利・敗北・撤退で履歴を廃棄する。
- ST16クリア・寿命90日・CD満了・前ターン履歴あり・現在HPより高い復元値を使用条件とする。HPを減らす復元や初回ターンは非消費拒否。物理消費0、省力薬による寿命軽減なし。
- HPだけを復元して通常反撃・毒・バフ・再生・CD経過を処理する。敵HP、寿命、物理/魔法エネルギー、報酬・アイテム・取引番号・乱数・効果残数などの巻き戻しは行わない。発動後の反撃によりHP純増がない場合も成立行動として寿命消費・熟練度+1・独立CD8。敗北時返還なし。
- 時間逆行装着戦闘だけにrewindHistory（現在turn、現在行動開始HP、前行動開始HP）を保存。履歴欠落/不正型/範囲/turn不一致/現在HP不一致/非装着戦闘の履歴を拒否。初回のみpreviousHp=null、以降は正整数必須。旧非装着戦闘の保存形式は維持。既存の保存後公開・世代/turn検証・snapshot照合を利用する。
