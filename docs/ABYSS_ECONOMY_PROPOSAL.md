# ABYSS SYSTEM 経済基盤

## 今回の範囲
WorldStateに魔晶石残高とショップ取引番号を追加する。既存セーブで項目がない場合は0、存在する場合は非負整数のみ許容する。G、武装券、物資券、寿命、旧ガチャ券とは別資産であり、移行・初期配布は行わない。

ショップの固定商品は素材ID、支払通貨、価格、数量を保持する。今回の対象は素材購入のみ。戦闘中禁止、取引番号照合、残高・素材加算上限、商品参照を検証し、作業用Stateを保存成功後に公開する。分解・保護設定と共有busyを利用する。保存済み取引番号により同一セーブ世代の重複購入を拒否する。

## 経済案（未承認）
Gは戦闘など既存の供給経路から獲得し、素材購入・強化などに消費する。魔晶石は将来の装備分解報酬・素材交換等に利用する案。今回魔晶石の獲得処理は追加しない。既存の素材直接還元案との関係は別途決定する。

試験用商品は鉄2個/10G、合金1個/魔晶石3個。正式価格・報酬・交換レートではない。本番カタログは空のままとする。価格・数量の技術上限100万はバランス上の承認値ではない。

## 残課題
魔晶石の正式獲得・消費方針、分解報酬、ショップ画面、正式商品価格、全装備操作共通busy、素材供給とG収支、券循環、強化補正・正式レシピ、実機・正式署名。既存召喚・強化・分解の無効状態を維持する。手動バックアップで過去世代を復元した場合の巻き戻し防止は対象外。旧アプリへ戻すと新規項目が保存時に失われる可能性があるため、ダウングレード前にバックアップを保持する。
