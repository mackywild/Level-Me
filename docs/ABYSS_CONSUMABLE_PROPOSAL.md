# 回復アイテム基盤

## 今回の範囲
HP・物理エネルギー・魔法エネルギーを対象に、最大値に対する割合回復を定義する。使用は戦闘外のみ。個数1を消費し、回復量は最大値を基準とした整数切り捨て（最低1）、不足量を上限とする。満タンなら消費しない。割合・丸め・満タン時の扱いは正式承認前の実装案である。

Controllerでは作業用Stateに自然回復を先に反映してから使用条件を検証する。失敗時は作業用Stateを破棄し、成功時のみ消費・回復・使用番号を一括保存して公開する。共有inventoryBusyを使用し、同一セーブ世代内で使用番号の再送を拒否する。画面確認に備え復元世代を必須引数とした。旧セーブに使用番号がない場合は0、不正型・負数は拒否する。

## 試験用定義と本番制約
HP20%、物理15%、魔法50%は試験値であり、本番カタログは空。既存素材マスターと正式な回復品の統合は行っていない。本番マスター設定経路では非空の回復カタログを拒否する。直接依存注入は試験用。既存の召喚・強化・分解・ショップの無効状態を維持する。

## 後続
