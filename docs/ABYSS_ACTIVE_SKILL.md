# 能動スキル戦闘実行基盤

試験用物理攻撃型のみ。戦闘開始時に習得・装着済みかつ実行定義のある能動スキルを固定し、ID・名称・威力割合・物理消費・CDを保存する。既存の物理ダメージ、攻撃/会心バフ、永続乱数、消費軽減、反撃・状態効果・敵再生・勝利報酬処理を利用する。自己加速の紅爪残回数は消費しない。発動ターンは自身のCD減算を免除し、後続の通常/アイテム/スキル行動で減算。戦闘終了で消滅。既存コマンド、寿命、停止系共有CD、解放条件は変更しない。

Controllerは戦闘ID・ターン・復元世代を照合し、作業用stateを保存後公開する。非空snapshotは現行装着実行定義との完全一致を必須とする。旧戦闘の空snapshotを許容し、途中からスキルを追加しない。マスター変更時の移行・空snapshotと旧形式の厳密な区別は本番前に決定する。試験用定義以外は実行定義なし、本番空catalog・skillEnabled=false維持。個別性能、習得条件、消費、CD、魔法/寿命/時間干渉系の処理は未承認。RV-084の競合解消は後続。

消費軽減・CD・乱数・不足・未装着・旧要求・勝敗・不正snapshot/CD・未承認定義・実ファイル保存失敗/再起動/再試行を試験。遅延保存、非致死実ファイルCD継続、複数スキル、全アイテム経路、時間停止、外部/端末内復元、UI widget、戦闘開始競合は追加検証が必要。RV-065〜084等本番安全性ゲート維持。ローカルFlutter実行・実機・正式署名未確認。最新CI全成功とレビュー承認がマージ条件。
