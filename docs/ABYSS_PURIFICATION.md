# 状態異常・浄化薬の基盤

状態異常は有利なバフ、時間遅延・停止・自己加速とは別の statuses として戦闘状態に保存する。旧セーブで欠落する場合は空、未知種別・不正持続・nullは拒否する。現段階の毒は試験用候補であり、最大HPの5%（切り捨て、最低1）、3ターン、HP1を下限とする。反撃後に生存している場合のみ毒を適用し、その後に継続回復を行う。時間停止でもプレイヤーの毒は経過する。毒の付与経路はまだ実装せず、既存敵に状態異常能力を追加しない。

浄化薬（item:purification、SR候補）は戦闘中1個使用、状態異常をすべて解除してから反撃を受ける。対象なしは非消費拒否。既存バフ・自己加速・停止CD等は通常ターン終了処理に従う。戦闘ID・ターン・使用番号・復元世代を照合し、作業用stateを保存成功後に公開する。状態異常と消費・反撃・結果を一括保存する。浄化カタログが空の場合は共通保存検証で非空statusesを拒否する。試験用カタログ注入時のみ既知状態異常を復元可能。将来の正式運用では浄化アイテムの提供可否と状態異常の許可種別を分離する。

候補マスターのpurificationEnabled=falseを維持し、true等の不正値、素材/回復/バフとのID衝突、召喚参照を拒否する。名称、希少度、毒の性能・致死性・持続、浄化範囲・適用順序・価格・供給は未承認。既存候補の本番無効も維持。

旧セーブ、不正状態異常、毒経過/HP下限、浄化対象・バフ維持、対象なし非消費、候補検証、実ファイル起動拒否・模擬保存失敗・再起動同一結果・再送拒否の試験を追加。状態異常付与、複数状態異常、停止/敗北/勝利/回復・バフ競合、外部/端末内復元とjournal、UI widget、毒のバランスは後続。RV-065〜073等本番安全性ゲート維持。ローカルFlutter・実機・正式署名未確認。最新CI全成功とレビュー承認がマージ条件。
