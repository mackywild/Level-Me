# 致死耐性アイテム

不屈薬（item:buff_lethal_protection、SSR）は未承認候補。戦闘中に1個使用し、戦闘終了まで致死ダメージを1回だけ防ぐ。使用行動も1ターン消費し反撃を受けるが、その反撃にも耐性が適用される。非致死・回避成功・反撃省略時は消費しない。防御・時間遅延等の既存補正後の実ダメージが現在HP以上の場合、HP1を残し効果を消滅させる。その後、既存の生存時継続回復を適用する。発動済みなら再使用可能（戦闘ごとの使用回数上限は未承認）。未発動中の同種使用は拒否する。撤退・勝利・敗北で効果は消滅する。寿命や報酬は変更しない。
