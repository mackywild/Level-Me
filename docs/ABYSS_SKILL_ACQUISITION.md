# スキル習得条件・費用管理基盤

試験カタログのSkillAcquisitionに必要プレイヤーLv、メインステージクリア、前提スキル1種と必要熟練Lv、ゴールド/魔晶石費用を設定する。すべてAND条件。指定なしはLv1・ステージ条件なし・前提なし・無料（既存試験との互換用）。習得時にControllerが作業用stateの経験値から算出したLvを使う。存在しないステージ/前提ID、自己参照、循環、実行定義なしの前提Lv2以上、不正範囲を拒否する。ステージ条件を持つ試験カタログはWorldCatalog読込後に生成する。個別条件・通貨選択・費用0〜100万/必要Lv上限100万は暫定制約であり正式性能ではない。

習得可否の表示と実行は共通判定。戦闘中・未公開・重複・変更番号上限・条件未達・残高不足は非消費。成功時のみ両通貨を減算し習得記録0と変更番号+1を同時保存。自動装着しない。世代/期待変更番号必須照合、作業用state保存成功後公開、同時要求拒否を維持する。前提条件は習得時に評価し、既習得の保存は現行マスターの価格や条件による再購入・再判定を要求しない。条件変更時の既習得権利/マスター移行・履歴検証は後続。

管理画面に条件・費用・残高・最初の不可理由・確認を表示する。実行時は再判定する。候補42種への正式条件設定は行わず、skillEnabled=false・空公開カタログを維持する。

全条件、各残高不足と一致、循環/未知/不正条件、戦闘/変更番号上限、実ファイル遅延保存/失敗/再試行/二重要求/再起動/外部復元の試験を追加。Controllerでの実Lv/進行度/前提熟練連携の追加試験、戦闘開始・他通貨取引との両順競合、端末内復元/journal、不正原本保護、画面widget、複数前提やOR条件、習得費用の正式決定は残る。RV-065〜094安全性ゲート維持。ローカルFlutter・実機・正式署名未確認。最新CI全成功とレビュー承認がマージ条件。
