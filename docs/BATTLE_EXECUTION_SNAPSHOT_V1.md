# 戦闘実行規則v1の保存基盤

LM-03の戦闘再開互換性、LM-04 D06とRV-086/117/126/129の段階的改善。LM-02付録Bの紅眼解放は能力強化・寿命120日だが具体値未決。時の終焉は400%/600%競合。未決事項を勝手に確定しないため、奥義追加より先に保存基盤を整備する。

## 新規戦闘
- WorldBattle.executionVersion=1を保存。activeSkills、skillCooldowns、lifeRewardBonusesは空でも明示し、lifeRewardPercentは100〜130の整数として保存する。v1の寿命率は装着効果の加算率と一致することを検証し、勝利時は保存した数値を適用する。
- 版付き戦闘は版番号・必要フィールド・各能動定義の全8項目・寿命率の型と整合性を厳密検証。未知版は拒否。装着能動/報酬snapshotを空の場合もSkillCatalogで照合する。報酬率だけの改変も拒否する。
- 版番号導入前の戦闘は現行の旧互換経路を維持。過去の率や装着を推定・補完して版付きへ昇格しない。旧保存に版だけを追加する移行は行わない。world.version=1、外部バックアップ形式、既存スキル性能は変更しない。
- 新規戦闘以外の既存フォーマットは維持。本番マスター変更なし、skillEnabled=false/公開catalog空維持。

## 検証と限界
8件の新規回帰試験と既存捕食・戦闘・バフ試験を更新。空snapshot・必須項目/版/率/定義欠落・装着不一致・旧互換・勝利時の数値率・実ファイル再起動/能動勝利/二重報酬拒否を対象とする。
この版番号は初期の保存契約であり、将来の規則v2実装・旧版ルール保持・マスター更新時の移行処理は未実装。敵基本報酬/敵能力、個別の効果率・持続・解放条件・CDグループ等は現行コード/マスター参照のまま。版番号と関連項目をまとめて除去する意図的な旧形式偽装や、範囲内の整合した改変の完全防止は対象外。署名等による真正性保証ではない。RV-071/086/089/092/104/107/110/113/117/120/123/126/129は部分改善のみ、RV-065〜129を維持。競合/遅延保存/外部・端末内復元/journal/実機/正式署名は追加検証対象。ローカルFlutter未実行。
ユーザー合意によりmain CI #256実行中からDraft開発開始。失敗判明時は復旧優先。最新HEAD全CI completed/success・レビュー承認・main健全性確認後のみマージ。

## RV-130修正・RV-131/132の扱い
- v1の非条件付き出力は全て必須とする。乱数の版/状態、バフ/状態異常、停止CD/加速残数/自然回復余り、戦闘ID/turn/敵HP/能力値/ログ/スキル/報酬を読み込み冒頭で型検証する。欠落/null/誤型はFormatException。会心率は有限の0〜1の数値。条件付き覚醒/逆行履歴と各項目の従来の範囲検証も維持する。旧形式だけ従来の既定値補完を許容する（旧形式でも不正な乱数片側欠落・バフ/状態異常の明示nullは拒否）。既存旧形式テストのfixtureからv1専用項目を除去する。
- RV-131：旧版実行規則の保持・マスター移行は未実装。保存された数値率と現在のenum/定義の一致を検証するため、将来の変更後の再開は保証しない。
- RV-132：PR77以前のreaderはlifeRewardBonuses:[]を拒否する。v1戦闘中セーブの旧アプリへのダウングレード互換は保証しない。更新前に戦闘を終了し外部バックアップを取得する運用を推奨。ロールバックは更新前の互換バックアップを使用し、新形式の原本は別途保全する。既存の復元検証に従い、不適合データを黙って旧形式へ書き換えない。専用エラー表示・実ファイルでの旧→新移行/外部・端末内復元/journal原本保護/非致死保存失敗/遅延/競合は残課題。RV-065〜132維持。
