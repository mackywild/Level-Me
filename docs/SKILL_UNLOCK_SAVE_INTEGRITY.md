# スキル解放・戦闘保存整合性

RV-137およびRV-120の部分改善。既存のスキル実行規則v1と戦闘保存v3の形式・性能は変更しない。

## 検証契約
- 実装済みの特殊能動IDと効果の対応を固定し、汎用物理等への置換・未来視の別ID・特殊IDの効果なし/受動定義を拒否する。既存の個別倍率・寿命・CD等の検証を維持。必要STが存在しないmaster定義も拒否する。
- 戦闘開始前に能動snapshot全件の必要STを確認し、不足時は自然回復・連番・乱数・戦闘生成前に拒否する。WorldState復元時には版なし/v1/v2/v3の全保存能動snapshotを検査する。超時連撃のST06・12両条件を維持。戦闘中の実行時チェックも維持する。
- SkillCatalogで習得済み全スキル（能動/受動・未装着含む）の持続する条件（習得定義のST、実行規則のST、前提習得・前提熟練度）を照合する。装着、習得時の進行条件判定も共通化。Controllerのスキル変更保存前、戦闘開始前、保存/起動/復元validatorで利用する。習得時の通貨支払・当時のプレイヤーLvを後から再要求しない（歴史的な支払・Lvの証跡は保存しない）。既存の装着ID・kind・snapshot定義の照合を維持する。
- 覚醒CDが正の場合、成立可能な最短turnは2+独立CD上限-残CD。これより早いturnを拒否する。既存の覚醒残turnとCDの関係検証も維持する。
- 正常な旧版保存は従来形式を維持するが、従来許容された不整合（未解放特殊snapshot等）は拒否する。黙ってSTや熟練度を補完しない。旧master変更による正当な習得の救済移行は別途設計。原本を保持し互換バックアップを用いる。
- 本番master変更なし、skillEnabled=false/公開catalog空維持。正式性能・解放条件の承認ではない。
