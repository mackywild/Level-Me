# 戦闘報酬の整数上限対策

RV-134の勝利報酬加算対策。G・召喚券・補給券はDartネイティブの符号付き64bit整数上限（9223372036854775807）まで許可する。報酬を切り捨てたり上限に丸めたりせず、残容量の比較で超過を拒否する。寿命は従来のBigIntのまま。

## 実行契約
- 戦闘開始前に、Gと初回対象の券（主戦3枚、自由戦1枚）の加算可能性を検証する。解放条件の確認後、自然回復・連番・乱数・戦闘生成前に拒否する。再戦で券は検査・追加しない。報酬0で残高上限ちょうどは許可。
- 既に戦闘中の保存データや旧形式も考慮し、ダメージを与える通常コマンド/能動スキルは、非致死攻撃であっても勝利報酬の容量不足時に事前拒否する。寿命・エネルギー・乱数・CD・turn・熟練度・勝敗を変えない。攻撃前検査は保守的な方針であり、容量不足時に戦闘を継続するための攻撃は許容しない。防御・非攻撃スキル・撤退は従来の可否判定を維持する。撤退後に該当資源を消費して再戦可能な場合は再戦する。
- 勝利確定時にも同じ検査を行い、G・寿命・券・初回クリア集合の一括更新前に拒否する。v2/v3では固定敵報酬、旧形式/v1では従来の参照方式を利用する。既存の寿命報酬率・初回券個数・戦闘性能・保存形式は変更しない。
- 開始画面と攻撃ボタンで上限理由を表示し、既存の実行時チェックも維持する。本番masterやskillEnabled=false/空catalogは変更しない。
