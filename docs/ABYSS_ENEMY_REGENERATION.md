# 敵HP再生・再生抑制

敵マスターの任意項目 regenerationPercent は整数0〜100、欠落時0。既存本番マスターは変更せず全敵0を維持する。再生は反撃処理後、双方生存時のみ、最大HP基準の切り捨て・最低1・最大HP上限。回避成功でも敵が行動した場合は再生し、時間停止成功による反撃省略時は再生しない。時間耐性で停止無効なら再生する。撃破・敗北・撤退後に再生しない。

再生封じ薬（item:buff_regeneration_suppression、SR）を未承認候補とする。再生基礎量を50%軽減し切り捨て、0回復も可能。発動時の敵再生から適用、以後3ターン持続（発動時を含め最大4回の再生機会）。再生能力なしの場合は消費前に拒否。同種重複不可、異種併用可、戦闘終了で消滅。既存バフ取引、使用番号/戦闘ID/turn/復元世代、保存後公開、乱数状態の永続化、未承認保存効果拒否を維持。敵再生自体は乱数を消費しない。敵再生率は現行敵ステータス同様にマスター参照であり、将来変更時の戦闘中スナップショット・バージョン移行は別途設計が必要。

本番buffEnabled=false、空カタログ、召喚・販売未登録。名称/希少度/率/期間/丸め/発動条件/停止との関係/敵能力割当/価格/供給は未承認。既存敵マスター0、不正値、再生/抑制数値・上限・0回復・満了・再生なし拒否、停止/耐性、勝敗、実ファイル保存失敗/再起動/再送/未承認起動拒否を試験。回避/致死耐性/再生併用、回復アイテム経路、外部/端末内復元、widget試験、強敵バランス、マスター変更互換性は残課題。RV-065〜070等本番安全性ゲート維持。ローカルFlutter・実機・正式署名未確認。CI全体成功とレビュー承認がマージ条件。
