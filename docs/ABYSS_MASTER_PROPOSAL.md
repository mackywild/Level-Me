# 深淵マスター初期案（LM-02 v1.1 第5〜7節）

## 目的
序章の N/R/SR/SSR に対し、武装20種・魔遺物4種・素材8種の最小排出候補を用意する。210装備・150非装備という設計書の仮目標は今回の完成条件ではない。

## 数値案
現行初期値は物攻40、魔攻45、防御10。装備は加算のみ、手部武器は今回入れず、素手の紅爪を維持する。防具・アクセサリで少量の補正を得る案。Nは1〜2、Rは1〜4、SRは1〜6、SSRは2〜10程度の単項目補正とする。複数装備時の合計と序章敵の難易度は要検証。詳細は assets/master/abyss_master.json を正本とする。名称・希少度割当・性能はすべて暫定提案であり承認済みではない。

魔遺物は汎用の能力値補正のみの候補。壊れた懐中時計、逆転の砂時計、紅爪の魔石の固有効果は未実装のため排出対象に含めない。瞳、権能、トカイ討伐品、寿命結晶も対象外。物資は設計書記載の素材8種に限定し、使用効果を持つ消耗品は後続フェーズで追加する。

## 承認ゲート
- enabled=false の場合、データを検証するがゲームには空カタログを公開する。
- true に変更するPRで性能値・排出対象を承認し、実機・難易度・券循環を確認する。
- 既存プレイヤーへの券配布や旧券移行は変更しない。
- 正式公開後のID・部位・希少度変更は装着済みデータや保留計画に影響するため移行方針を必須とする。
- マスターの承認フラグは配布時の開発者による管理であり、改造端末に対するセキュリティ境界ではない。

## 承認差分の必須確認
ローダーは手部武器、UR以上、素材以外の物資、不完全なプールを無効状態も含めて拒否する。ただし名称やIDだけから瞳・権能・トカイ討伐品・寿命結晶等の意味を自動判定することはできない。承認PRでは全候補を設計書と照合し、禁止品や未実装効果の混入がないことを人手で確認する。マスター読込に失敗した場合は起動・外部復元・端末内復元のいずれもファイル更新前に停止する。RETRYで再読込可能。

## 保留取引の互換性と排出情報
- 保留計画の記録済みID・希少度・プール区分を現在のマスターと照合する。候補が欠落・不一致の場合、ロード・復元を拒否し原本を保存する。戦闘や券不足は再開時の条件とし、ロード自体は拒否しない。
- 解放段階が進んでも既存計画の結果・天井値は保持し、新規抽選用の候補の追加を要求しない。候補の追加・並べ替えで再抽選しない。
- 保留計画は名前・性能・非魔遺物内の部位を保存していないため、それらの変更を自動検出しない。公開後は既存IDの意味・部位・希少度・性能を変更しないことをリリースレビューで確認し、必要なら明示的な移行を別PRで実装する。自動移行・補償・削除は行わない。
- 個別通常確率は解放済み希少度の重みを同希少度の候補数で等分した値。表示は小数4桁に丸めるため、表示合計には誤差が生じる。天井・10連保証による変動は含まない。不完全または無効なプールは個別確率を公開しない。
- 手動バックアップによる過去世代への巻き戻しは防止対象外。保留状態を復元した世代内での二重実行のみ防止する。
