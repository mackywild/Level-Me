# 戦闘バフ基盤

攻撃+25%（3ターン）、防御+40%（3ターン）、継続HP回復5%（5ターン）を暫定案として実装する。攻撃は物理・魔法の攻撃倍率に乗算、防御は固定ステータスへの整数切り捨て補正、継続回復は最大HP基準の切り捨て・最低1・上限あり。同種効果が有効な間は使用拒否、異種は併用可能。発動ターンの防御補正は即時適用し、発動ターンは持続数を減らさない。継続回復は次の行動終了時から、反撃で生存した場合に適用する。時間停止による反撃省略時もターン経過する。効果は戦闘終了時に消滅する。これらは正式承認前の案である。

使用は戦闘中1コマンド、1個消費、通常反撃を受ける。戦闘ID・ターン・使用番号・復元世代を照合し、作業用Stateで消費・効果・反撃・結果を一括保存して公開する。旧セーブのbuffs欠落は空、未知種別・不正持続値は拒否する。本番カタログは空、正式マスター設定時の非空直接注入を拒否する。回復・召喚・強化・分解・商店の無効状態を維持する。

試験は再生・重複拒否・旧セーブ・不正値・実ファイル再起動を対象とする。攻撃防御の数値比較、満了・併用・敗北・保存失敗・復元競合の追加試験、バフ画面、候補マスター、会心・回避・浄化・特殊効果、正式性能・価格・供給承認は後続。旧版へ戻すと効果を失う可能性がある。実機/正式署名未確認、手動backup巻戻し・任意I/O障害は保証外。

## 追加効果・使用画面
会心率+25ポイント/3ターン（上限100%）、回避率+20ポイント/2ターンを未承認案として追加。回避は発動時の反撃を含め、敵反撃が実行される場合のみ乱数を1回消費する。回避成功でも時間遅延の残り回数は経過する。停止による反撃省略時・回避未発動時は回避乱数を消費しない。回避乱数の結果自体は永続化しないため保存失敗後の再試行で結果が変わり得る。正式有効化前に乱数確定保存方針を決める。状態効果の表示、使用確認、同種重複禁止をWORLDへ追加。候補5種をbuffs配列に登録し素材・回復品との衝突、区分、希少度、効果定義を検証。buffEnabled=trueは拒否する。候補は召喚/販売へ追加しない。既存の未承認効果復元拒否を維持。
固定乱数で会心・回避境界、回避満了/非発動時の乱数消費、候補検証、使用取消・確定・残りターン表示のwidget試験を追加。会心上限・停止中乱数非消費・回避保存失敗時の再抽選方針・画面再入場/競合・強い敵での攻防比較は未検証。通常/回復/バフのターン上限拒否を追加。正式性能・名称/希少度・価格/供給は未承認。本番バフカタログ空、他機能の無効状態維持。実機・署名未確認。
