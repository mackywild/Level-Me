# プレイヤー能力値生成の数値安全化

RV-145およびRV-141の部分対応。Dartネイティブ符号付き64bit整数を対象とする。正式な運用上限・ゲームバランスは未決のため、能力値を任意の上限に丸めず表現不能な構成を拒否する。

- WorldStats.fromRanksのHP/物攻/魔攻/防御は従来の係数をBigInt中間演算で評価し、最終値が0〜64bit上限である場合だけintへ変換する。全rank/levelは1以上必須。エネルギー上限の平方根は整数除算で境界補正し、会心率の式/上限は維持する。通常値の性能は変更しない。極端値の平方根の丸め差は修正する。
- LevelCalculatorはn回のレベルアップの累積EXP n(175+25n)/2 をBigIntで計算し、指数探索・二分探索で最大EXPにも対数時間で対応する。必要EXP・残EXP・レベルの既存境界を維持。直接の必要EXP計算は不正level/上限超過を拒否する。負のtotalExpの従来の0扱いは維持するが、負の属性EXPは拒否する。
- 装備強化は従来の個別切り捨てをBigIntで評価。強化無効・試験5%/level・+20上限は変更しない。装備と常時補正の加算に共通の事前検証を適用。上限ちょうどは許可、超過/負値は拒否。装備変更・強化は作業用状態の能力計算を保存前に検証し、保存成功後に公開する。既存の保存/復元validatorも共通計算を利用する。
- 戦闘開始時の能力固定、既存保存形式、本番master・公開設定は維持する。

新規6試験：通常レベル境界/必要EXP、最大EXP、通常能力式/平方根/上限/不正rank、強化率・中間積、装備と常時補正の上限/原本保持、実ファイル巨大EXP・装備保存失敗/再試行・戦闘固定/再起動。
EXPを付与する側の加算・旧ボス等の資源加算、その他G/券/素材/連番/時刻の監査、正式運用上限、巨大値のダメージdouble精度、競合/遅延/外部・端末内復元/journal/widgetは未対応。負属性EXPや表現不能な能力を含む旧データは自動修復しない。RV-065〜146の未解消項目を維持。ローカルFlutter/実機/正式署名未確認。
