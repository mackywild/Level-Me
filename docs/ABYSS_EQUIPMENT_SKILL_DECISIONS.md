# ABYSS SYSTEM — 装備スキル厳選の決定記録

決定日: 2026-11-26
根拠: LEVEL ME開発者との仕様相談・承認。対象は今回承認された範囲のみ。正式未決の詳細は仮値としても実装しない。

## DEC-001: 獲得経路と完全厳選

- 主人公固有の重要な時間系スキルはストーリー進行による覚醒で解放する。装備のランダム抽選とは独立する。
- 武器・防具系のスキルはガチャ・ショップ交換による装備収集と、装備強化によるランダム付与を中心とする。直接スキル書を交換する別経路の有無は未決。
- 付与されたスキルの種類・Lvは個体固有の結果として保持し、変更・再抽選・強化リセットは不可。理想の組み合わせを求める場合は別個体を入手し、素材を集め直して強化する。
- 既存承認済みの強化上限+20、成功率100%（実行条件を満たす場合）、破壊・消失なしを維持する。
- 周回、素材獲得、装備収集、強化、厳選を育成サイクルとする。

## DEC-002: 希少度別スキル枠とレベル

| 希少度 | 最大枠数 | 付与される強化段階 |
|---|---:|---|
| N | 0 | なし |
| R | 1 | +5 |
| SR | 2 | +5、+10 |
| SSR | 3 | +5、+10、+15 |
| UR | 4 | +5、+10、+15、+20 |
| LR | 5 | +4、+8、+12、+16、+20 |
| GR | 6 | +3、+6、+9、+12、+16、+20 |
| EX | 特殊 | 個別設定（未決） |

R〜GRで抽選Lvは1〜10。低希少度でもLv10の獲得可能性を残し、高希少度ほど高Lvが出やすくする。具体的な確率・EXの扱い・部位別のスキルプールは未決。強化段階に達するたび、その段階の枠に結果を記録する。以前に付いた枠を書き換えない。

## DEC-003: 重複スキルの加算

同じスキルが複数の装備から付与されている場合、適用可能な効果を加算する。例えば同一の物攻上昇効果が各+20%なら合計+40%であり、乗算の+44%や最高値のみの+20%にはしない。この数値は計算例であり正式性能値ではない。

- 加算は効果量の合算を意味する。抽選Lvを合計した新しいLvに置換する仕様ではない。
- 適用する基礎値、固定加算と割合加算の演算順、会心等の上限、異なる効果との重複、能動スキルの重複時の挙動は別途確定する。
- 同一個体内で同じIDを複数枠に抽選できるかは未決。複数装備での重複加算は確定。
- 既存SkillStateの能動6枠・常時3枠・同一ID重複装着拒否は現在の試験用習得・装着基盤の契約であり、装備個体の付与枠とは別概念。装備由来の能動/常時スキルとこの基盤の接続方法は未決。

## 次に確定する仕様

1. 装備由来の能動スキルは装着中だけ使用可能か、永久習得か。常時スキルの適用条件と既存6/3枠との関係。
2. 重要な時間権能の対象ID、ストーリー上の覚醒地点、その他の時間系・捕食・覚醒系の獲得経路。
3. 同一装備内の重複、部位別プール、スキルの効果/Lv曲線、加算順・運用上限、希少度別Lv確率、EX個別仕様。
4. 強化レシピ・素材供給・G費用、ガチャ/ショップ交換品、既存強化済み個体の移行方針。

## 実装計画（技術提案、未実装）

- 希少度別付与段階を純粋なポリシーに分離し、境界・枠数を試験する。EXは仕様確定まで有効化しない。
- 個体IDと付与段階に紐づく変更不能な付与結果（スキルID・抽選Lv等）を版付き保存する。旧形式の読み込みと既存強化済み個体の移行を設計する。
- 既存強化トランザクションと確定抽選を統合する。素材/G・強化値・付与結果は一括確定、保存失敗・再試行・再起動・二重要求で再抽選が発生しない方式を検討する。バックアップ復元による巻き戻しの扱いは別途決定する。
- 装備の付け替え・戦闘開始時の効果固定、加算境界、画面表示、図鑑、周回・素材供給を段階的に実装する。
- RV-150の旧抽選確定取引、RV-151の保存後公開、RV-152の旧データ移行を関連課題として維持する。RV-065〜149の未解消事項も継続管理する。
